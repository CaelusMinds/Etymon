# Code of Conduct

This project has adopted the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. Please read it: it describes the behaviour expected of everyone
taking part in this project, and what happens when those expectations are not met.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

It applies everywhere the project happens — issues, pull requests, discussions,
commit messages, and any space where someone is representing the project.

## Reporting

Report anything that concerns you by emailing **conduct@caelusminds.com**.

Reports are read by the maintainers, kept confidential, and answered. You will not
be asked to justify raising something, and you will not be put in a room with the
person you are reporting.

If a report concerns a maintainer, send it to any other maintainer directly; they
will handle it without involving the person reported.
